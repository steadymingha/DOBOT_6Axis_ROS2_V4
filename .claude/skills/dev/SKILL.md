# Development Workflow

## Rules
- TODO.md가 승인되기 전에는 절대로 코드를 작성하거나, 파일을 생성하거나, 명령어를 실행하지 않는다.
- 누락된 정보를 추측하지 않는다. 대신 사용자에게 직접 질문한다.
- 단계를 건너뛰지 않는다. 단계별 순서를 따른다.
- 계획에서 벗어나지 않는다. 새로운 작업이 발견되면 TODO.md에 추가하고, 수행하기 전에 승인을 요청한다.

—

## 1단계 - 프로젝트 분석

질문을 하기 전에 프로젝트의 주요 정보를 확인한다. 다음 사항을 읽는다:

1. 디렉터리 구조
2. 의존성 관리 파일 (`package.json`, `pubspec.yaml`, `go.mod`, `requirements.txt`, `Cargo.toml`, `pom.xml` 등)
3. 빌드 시스템 및 스크립트 (`Makefile`, `scripts/`, CI config)
4. `README.md` 또는 `README.*`
5. 기존 `TODO.md`, `TASKS.md`, `.todo` 또는 오픈 이슈 파일

질문과 직접적인 관련이 없는 한 분석 결과를 제시하지 않는다.

—

## 2단계 - 명확하게 질문하기

프로젝트 분석 후, 올바른 구현에 필요한 누락된 부분을 파악한다.

- `AskUserQuestion` 도구를 사용한다.
- 한 번에 하나의 질문만 한다.
- **중요하고 코드베이스에서 추론할 수 없는** 내용만 질문한다.
- 사용자가 선택해야 할 경우, 후보 선택지를 장단점과 함께 제시한다.

다음 단계로 진행하기 전에 사용자의 답변을 기다린다.

—

## 3단계 - TODO.md 작성

분석 결과와 사용자의 답변을 바탕으로 `TODO.md` 파일을 작성한다.

### TODO.md 구조

```markdown
# TODO

## Goal
개발하거나 수정할 내용을 한 문장으로 설명한다.

## Tasks

### 1. <단계 이름>
- [ ] <구체적이고 측정 가능한 작업>
- [ ] <구체적이고 측정 가능한 작업>
…

### 2. <단계 이름>
- [ ] <구체적이고 측정 가능한 작업>
- [ ] <구체적이고 측정 가능한 작업>
…

## 참고사항
제약 조건, 결정 사항 또는 위험 요소 등을 기록한다.
```

### 요구사항
- 작업은 **작고 독립적으로 검증 가능**해야 한다.
- 작업을 **의존 관계**에 따라 순서대로 정렬한다.
- 각 작업은 완료/미완료 여부로 확인 가능해야 한다.
- “문제를 해결한다” 또는 “코드를 개선한다”와 같은 모호한 항목은 포함하지 않는다.

파일을 작성한 후, 사용자에게 전체 내용을 보여주고 다음과 같이 물어본다:

```
TODO.md 파일을 작성했습니다. 이 계획이 올바른가요?
시작하려면 'YES'라고 답하거나, 변경할 내용을 알려주세요.
```

---

## 4단계 - 수정 루프 (필요한 경우)

사용자가 변경을 요청하는 경우:

1. 의견 차이를 해결하기 위해 구체적인 후속 질문을 한다.
2. `TODO.md`를 다시 작성한다.
3. 업데이트된 계획을 보여주고 다시 승인을 요청한다.

사용자가 승인할 때까지 이 과정을 반복한다.


---

## 5단계 - 계획 실행

사용자가 계획을 승인하면:

- 작업을 **순서대로** 하나씩 처리한다.
- 각 작업을 완료한 후, `TODO.md`에서 완료로 표시한다.
   - `- [ ]`를 `- [x]`로 변경한다.
- 작업을 완료한 즉시 완료 표시를 한다. 한번에 여러 작업의 완료 표시를 몰아서 하지 않는다.
- 작업을 시작하기 전에 어떤 작업을 시작하는지 명시한다.
- 현재 작업이 완료될 때까지 다음 작업을 시작하지 않는다.
- `TODO.md`에 나열되지 않은 작업은 수행하지 않는다.

목록에 없는 작업이 필요하다는 것을 발견할 경우:
1. 작업을 중단한다.
2. 사용자에게 발견된 내용과 그 필요성을 설명한다.
    - 필요시 사용자에게 질문한다.
3. 사용자가 승인하면 `TODO.md` 파일에 해당 작업을 추가한다.
    - [ ] (발견) <새로 발견된 구체적이고 측정 가능한 작업>

모든 작업에 `[x]` 표시가 완료되면 다음을 작성한다:
```
TODO.md의 모든 작업이 완료되었습니다.
```

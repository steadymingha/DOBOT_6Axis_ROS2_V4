## 참고사항
- 트리거 단위: **SPACE 1회 = 상자 1개**(사용자 확정). 상자가 멀어 reach 어려우면
  SPACE 사이에 AGV를 저속으로 재배치 가능(포켓 상자는 저속이라 따라옴).
- 상자 추종: 무게 증가는 마찰력(μmg)과 관성(ma)이 질량 상쇄되어 효과 불확실하므로
  채택하지 않고, **텔레옵 저속화 + 가속도 램프**로 해결(사용자 확정).
- 텔레옵은 사용자가 직접 실행하는 `teleop_agv.py`를 수정(launch 추가 아님).
- `place_ref`/`place_jaw_x`는 포켓 family가 동일하므로 어느 포켓으로 구해도 무방.
- 복귀 실패 0 보장 구조(박스부착 사전검증 + 역재생)는 변경 없이 그대로 재사용.
- `cbirrt_pick_place.py`는 수정 금지(참고용). 픽앤플레이스 변경은 `hub_pick_place.py`,
  텔레옵 변경은 `teleop_agv.py`에 한정.
- 기본 상자 순서는 a->b->c->d, 포켓은 -y->+y. sim에서 도달성/순서 문제 시 상수만 조정.

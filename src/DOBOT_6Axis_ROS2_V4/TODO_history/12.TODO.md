## Goal
hub_pick_place.py가 물고 있는 4개 파일(cbirrt_pick_place / test_w_gripper / constrained_cbirrt / reachability_map) 의존성을 끊고, 필요한 런타임 코드만 복사한 자립형 모듈 패키지 `cr7_pnp/`를 만든다. hub_pick_place.py는 "모듈 import + 선반 시퀀스 + main"만 남기고, 모듈은 이후 장비 시퀀스(linear servo) 스크립트가 그대로 가져다 쓸 수 있게 한다.

## 결정사항 (사용자 확인 완료)
- 3개 인프라 클래스를 모듈 안으로 **복사 내장**한다 (import가 아니라). 단 **런타임에 쓰는 부분만** 복사:
  - `ReachabilityModel` 클래스만 (reachability_map.py의 오프라인 맵 생성 코드 ~640줄은 제외)
  - `ConstrainedPlanner` 클래스 (dead인 `lift_path` 제외)
  - `CR7RRTPlanner`의 런타임 메서드만 (MoveIt `get_ik`/`is_state_valid`/`move_to_pose`/`move_to_joint_pose`/`move_to_coordinate`와 `ik_client`/`validity_client`는 override돼 죽은 코드라 제외)
- 모듈은 단일 스크립트가 아니라 **패키지**로 구성 (사용자가 허용).
- cbirrt_pick_place.py는 클래스·상수를 모듈로 옮기고, 파일은 `shelf_to_base_cycle` 데모 + main만 남겨 모듈을 import.
- **장비 시퀀스 스크립트는 이번 작업 범위 아님** (완료 후 사용자가 직접 작성). 이번엔 모듈이 재사용 가능하도록 노드+프리미티브만 노출한다.

## 모듈 구성 (`src/DOBOT_6Axis_ROS2_V4/cr7_pnp/`)
- `model.py`     — ReachabilityModel (IK + 충돌). reachability_map.py에서 클래스 + 상수만 복사.
- `cbirrt.py`    — ConstrainedPlanner (CBiRRT plan + linear_path servo). constrained_cbirrt.py 복사, lift_path 제거.
- `geometry.py`  — 순수 헬퍼(quat_to_R/quat_about_z/quat_mul/pose_at/wait_for_spacebar) + 작업공간/그리퍼 상수(DOWN, GRASP_*, POCKET_*, SHELF_*, BOX_* 등).
- `node.py`      — ROS2 노드 클래스. CR7RRTPlanner(런타임분) + CBiRRTPickPlace + HubPickPlace의 제네릭 메서드를 합친 재사용 노드. 선반 시퀀스 함수는 안 들어감.
- `__init__.py`  — 공개 API 재노출 (노드 클래스, 상수, 헬퍼).
